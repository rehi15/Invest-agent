# Excel 자동 수정 에이전트

## 역할
자연어 명령을 받아 지정된 Excel 파일의 셀 데이터 입력, 서식(배경색) 변경을 자동으로 수행하는 에이전트입니다.

## 사용 방법

### 단일 명령
```bash
python3 scripts/excel_agent.py --cmd "<자연어 명령>"
```

### 대화형 모드
```bash
python3 scripts/excel_agent.py --interactive
```

### 배치 실행 (JSON)
```bash
python3 scripts/excel_agent.py --batch commands.json
```

### 다른 파일 지정
```bash
python3 scripts/excel_agent.py --file path/to/file.xlsx --cmd "<명령>"
```

---

## 명령 예시

### 데이터 입력
```
구매 계획 시트 10행에 번호=설인-020, 투자규모=50 입력
5. 인프라그룹 시트 5행에 과제번호=설비-002, 과제명=레이저용접자동화, 진행현황=진행중 입력
```

### 서식 변경 (배경색)
```
10행 E열 배경색 노란색
8행~12행 배경색 초록색
5행 배경색 초기화
```

---

## 지원 색상
노란색, 빨간색, 파란색, 초록색, 주황색, 보라색, 회색, 흰색, 하늘색

## 지원 기능
| 기능 | 키워드 | 설명 |
|------|--------|------|
| 데이터 입력 | `입력`, `수정`, `변경` | `컬럼명=값` 형식 |
| 배경색 변경 | `배경색 <색상명>` | 단일 셀 또는 행 전체 |
| 배경색 초기화 | `배경색 초기화` | 색상 제거 |
| 행 범위 | `8행~12행` | 여러 행 동시 처리 |
| 자동 백업 | 자동 | 수정 전 타임스탬프 백업 |
| 배치 실행 | `--batch` | JSON 파일로 일괄 처리 |

## 배치 JSON 형식
```json
[
  "구매 계획 시트 10행에 번호=설인-020, 투자규모=50 입력",
  "10행 E열 배경색 노란색",
  "5. 인프라그룹 시트 5행에 과제번호=설비-002 입력"
]
```
